    How it's counted
    
    
    One GitHub search, shown here so you can run it yourself.
    
  
    
  
      
    
    • A pull request counts as an agent's when its text says Generated with Claude Code, or its branch starts with claude/, codex/, cursor/ or copilot/. Those are the default signature and branch names these agents use.
      • 
    
    • The query: is:pr is:public created:>24h ("Generated with Claude Code" OR head:claude/ OR head:codex/ OR head:cursor/ OR head:copilot/), read from the count GitHub's search API returns.
      • 
    
    • It undercounts. Private repositories are invisible, and so is agent work that carries no signature or runs under a bot's own account. It can also count a person who names a branch codex/… by hand.
      • 
    
    • Most of these pull requests are opened in the author's own repository. A merged pull request there says little about quality; the board shows volume, not a ranking of agents.
      • 
    
    • Your recap and a repository's report are fetched by your browser from GitHub's public API, which allows ten searches a minute per network. We store a count of recaps made, not who was looked up.
      • 
    
    • If you claim your pass, GitHub signs you in with public information only. Your numbers are then counted once with your own sign-in and stored with your username, so your pass, the board and the badge load without asking GitHub again. The access token is deleted when the count is done.
